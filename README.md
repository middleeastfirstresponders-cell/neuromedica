# نيوروميديكا — Next.js

صفحة هبوط لشركة نيوروميديكا (مؤتمرات، تدريب، منح تحاليل طبية وإسعافات أولية).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## التعديل

- المحتوى: `app/page.js` (النصوص بين [ ] أماكن تكتب فيها بياناتك)
- الألوان: المتغيرات في أول `app/globals.css`
- العنوان والوصف: `app/layout.js`
